## 🔬 Current Research

A lot of my current interest sits at the intersection of **machine learning, evolutionary computation, and optimization**.

- **Escaping local optima in evolutionary search** — exploring adaptive search strategies that dynamically balance exploitation and exploration rather than relying on fixed mutation schedules.
- **Hybrid optimization methods** — investigating ways to combine gradient-derived information with genetic/evolutionary operators while preserving the broader search behavior that makes population-based methods useful.
- **AI evaluation & agent behavior** — experimenting with ways to measure model behavior, robustness, and performance beyond simple task-completion metrics.
- **LLM-assisted software development** — using modern coding agents and LLM workflows as part of the engineering process, with an emphasis on where they meaningfully improve iteration speed and where conventional engineering discipline still matters.

## 🧪 Selected Projects

### [trenchPilot](https://github.com/orcasmedialab/trenchPilot)
A browser-based 3D drone flight game built with JavaScript and Three.js. Navigate hostile terrain, manage limited battery life, and locate the target before time runs out.

### [flappyBots](https://github.com/orcasmedialab/flappyBots)
Flappy Bird rebuilt as an evolutionary-learning experiment. Populations of agents improve across generations using a genetic algorithm rather than conventional gradient-based training.

### [lineupSim](https://github.com/orcasmedialab/lineupSim)
A baseball simulation engine for testing batting-order optimization. Runs repeated seasons across lineup permutations to explore how ordering decisions affect expected offensive output.

### [frictionlessFootsteps](https://github.com/orcasmedialab/frictionlessFootsteps)
Experimental work around AI evaluation, model behavior, and the less-visible failure modes that can appear even when an AI system seems to complete a task successfully.

### [parkingChecker](https://github.com/orcasmedialab/parkingChecker)
A small Python/Selenium automation built to monitor Crystal Mountain parking availability and alert when a target date becomes available.

### [screenMachine](https://github.com/orcasmedialab/screenMachine)
One of several small utilities built around automating repetitive workflows and solving annoyingly specific real-world problems.

## ⚙️ How I Like to Build

I tend to gravitate toward projects where software interacts with an uncertain system: optimization problems, simulations, autonomous agents, automation, or physical products that require both engineering and experimentation.

The usual pattern is:

<p align="center">
  <strong>Find an interesting problem → build the smallest useful model of it → experiment aggressively → keep the parts that survive contact with reality.</strong>
</p>

My work spans **Python, JavaScript/TypeScript, C/C++, AI/ML tooling, browser automation, simulation, data systems, and increasingly agent-driven development workflows**.

Orcas also develops and operates commercial products, but this GitHub account intentionally leans toward the engineering, software, research, and experimental side of the studio.
